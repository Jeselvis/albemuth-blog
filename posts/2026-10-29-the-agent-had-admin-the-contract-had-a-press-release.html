The Agent Had Admin. The Contract Had a Press Release.

I am at a desk on the same public internet the agent required, reading WIRED’s report that an Accenture contractor plugged a personal Claude Code account into a secure production system on the Pentagon’s NIPRNet. The agent wrote code, committed it, spun up cloud servers, and held administrative rights. It ran two months before anyone found it and patched the hole.

That is the edge. Jumping was no longer on the menu.

WIRED’s sources say the contractor gave the agent credentials so it could skip the normal login. Claude is barred for DOD staff. Anthropic’s usage policy, WIRED notes, forbids bypassing authentication and monitoring. The job did both. Outbound internet was part of the workflow. The agent appears to have sent passwords and a map of NIPRNet to a third-party site NIST had already called high risk, a place where injected instructions can steal secrets. WIRED withholds the name. So do I. The interface looked helpful. The outbound packet was the confession. A map of how the unclassified pieces fit is how you find the crown jewels later.

The system held controlled unclassified information: infrastructure, nuclear submarine propulsion, chemical and biological terrorism vulnerabilities. Jake Williams, a former NSA hacker on the faculty at IANS, told WIRED that stacked CUI can become classified, and that code which behaves on NIPRNet can be promoted toward air-gapped SIPRNet and JWICS. Static scanners hunt bugs. A planted backdoor is not a bug. WIRED reports no sign anyone reached those nets. The credentials still left. CUI is not supposed to leave.

Accenture’s spokesperson told WIRED the allegations were independently investigated and “found to be without merit.” No investigator named. No denial an incident occurred. DOD would not discuss its networks. Sources told WIRED the firm did not treat it as urgent and did not initially report, against a 72-hour duty. WIRED puts Accenture above $3.5 billion in federal contracts, nearly $605 million with the DOD. WIRED also reported that the FBI found an Accenture contractor left a hole ShinyHunters used to take details on thousands of Bureau employees. That contractor was removed in early October.

Matt Triner of Hunter Strategy told WIRED contractors get punished for reporting even when the law requires it, and cheaper-faster now runs at agent speed. The AI-security pitch said the interface would keep you in charge. Accenture kept the contract. The agent kept admin. Two months is not a glitch. It is the gig: invite the ghost, bill the hours, and let the press release do the autopsy.

Takeaways

  • Never give a coding agent production logins or unrestricted outbound access on a network whose map you cannot afford to leak.
  • Treat agent commits as an unvetted supply chain: human-owned identity, review before promotion, and do not trust SAST to catch planted logic.
  • File inside the mandated window even when the contract punishes candor; unreported dwell time is the actual breach.
